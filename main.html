Basic Fundamental of HTML

The basic fundamentals of HTML are the main building blocks used to create a webpage. HTML stands for HyperText Markup Language. It structures the content of a website.

HTML STRUCTURE

Every HTML page usually starts with:

<!DOCTYPE html>
<html>
<head>
  <title>My Website</title>
</head>
<body>

</body>
</html>

TAGS

HTML Uses Tags to create elements. 

<p>Hello World</p>

ELEMENTS

an element is a full tag with content

<h1>Hello World</h1>

HEADINGS

used for titles

  <h1> Hello World</h1> biggest heading
  <h2> Hello World</h2>
  <h3> Hello World</h3>
  <h4> Hello World</h4>
  <h5> Hello World</h5>
  <h6> Hello World</h6> smallest heading

TEXTS TAG

 
<p>Hello</p> for normal text blocks.
<em>hello</em> to emphasize text.
<strong>hello</strong> strong text.

LINKS

go to another page

  <a href="link">world</a>

IMAGES, AND GIF

shows pictures

  <img src="img.png">

List Item & Unordered 

  
 List Item

  <ol>
    <li> Banana </li>
    <li> Apple </li>
  </ol>
  
  
 Unordered

    <li> Banana </li>

DIV (Container)

used to group element

  <div>
